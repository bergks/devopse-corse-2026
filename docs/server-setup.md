# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
*   Объём памяти: 2048 МБ
*   Количество ядер: 2
*   Объём диска: 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
*   Адаптер 1 (NAT): полученный адрес 10.0.2.15. Назначение: доступ в Интернет для обновления пакетов.
*   Адаптер 2 (Host-only): полученный адрес 192.168.56.102. Назначение: прямое подключение с хостовой системы по SSH и доступ к веб-сервисам.

## 3. Правило проброса портов
*   Порт хостовой системы: 2222
*   Порт гостевой системы: 2222 (SSH)

## 4. Учётные записи
*   `student`: принадлежит к группе `student`, аутентификация по паролю (используется для локального входа и первоначальной настройки).
*   `devops`: принадлежит к группе `sudo`, аутентификация по SSH-ключу (используется для удаленного администрирования).

## 5. Служба SSH
*   Порт: 2222
*   Изменённые директивы: `PermitRootLogin no`, `PasswordAuthentication no`, `PubkeyAuthentication yes`, `MaxAuthTries 3`, `AllowUsers devops`.
*   Расположение файла конфигурации: `/etc/ssh/sshd_config.d/99-hardening.conf`

## 6. Правила межсетевого экрана (UFW)
*   Политика по умолчанию: deny incoming, allow outgoing.
*   Разрешенные правила: 80/tcp (HTTP), 443/tcp (HTTPS), 2222/tcp (SSH с ограничением частоты LIMIT).

## 7. Снимки состояния
*   `01-clean-install` — создан после установки ОС и обновления.
*   `02-keys-configured` — создан после настройки ключевой аутентификации.
*   `03-ssh-hardened` — создан после усиления безопасности SSH.
*   `04-dns-configured` — создан после настройки локального доменного имени.
*   `04-nginx-https` — создан после настройки Nginx с HTTPS.

## 8. Веб-сервер
*   **Устанавливаемый пакет:** `nginx` (установлен из официального репозитория Ubuntu).
*   **Путь к конфигурации ресурса:** `/etc/nginx/sites-available/devops-site` (активирован через символическую ссылку в `/etc/nginx/sites-enabled/devops-site`). Стандартный ресурс `default` отключен.
*   **Каталог ресурса:** `/var/www/devops-site`.
*   **Владелец каталога ресурса:** `devops:devops`.
*   **Права на каталог ресурса:** `755` (владелец может писать, остальные — только читать и заходить).
*   **Путь к сертификату:** `/etc/ssl/certs/devops.crt`.
*   **Права на сертификат:** `644` (владелец `root:root`, доступен для чтения всем).
*   **Путь к закрытому ключу:** `/etc/ssl/private/devops.key`.
*   **Права на закрытый ключ:** `600` (владелец `root:root`, доступен только владельцу).
*   **Команда формирования самоподписанного сертификата:**
    ```bash
    sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout /etc/ssl/private/devops.key \
    -out /etc/ssl/certs/devops.crt \
    -subj "/CN=devops.local" \
    -addext "subjectAltName=DNS:devops.local"
    ```
*   Срок действия сертификата: 365 дней.
*   Настройки TLS: разрешены протоколы TLSv1.2 и TLSv1.3. Настроен принудительный редирект с HTTP (порт 80) на HTTPS (порт 443).
*   Доставка содержимого: осуществляется утилитой rsync из локального репозитория (ветка feature/web-deploy) в каталог /var/www/devops-site/ с принудительной установкой прав (--chmod=D755,F644).
