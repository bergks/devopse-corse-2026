# Мой пет-проект

**Идея:** Одностраничный сайт-визитка с портфолио, тёмной темой и адаптивной вёрсткой. Будет размещён на GitHub Pages.

**Стек:** HTML, CSS, JavaScript (Vanilla)

**Цель:** научиться верстать адаптивные сайты с нуля и освоить деплой через GitHub Pages.

**Сроки реализации:** проект планируется выполнить в течение одного учебного семестра
