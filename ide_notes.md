# IDE vs CLI: заметки по работе с Git

## 3 вещи, которые удобны в VS Code

1. **Визуализация diff.** В панели Source Control можно кликнуть по изменённому файлу и увидеть разницу между старой и новой версией бок о бок. Не нужно вводить `git diff` и читать вывод в терминале — всё наглядно: добавленные строки зелёные, удалённые красные.

2. **История коммитов в виде графа.** Вкладка Source Control Graph (или GitLens) показывает всю историю коммитов визуально: ветки, слияния, порядок. Это быстрее, чем `git log --oneline --graph`, потому что можно кликать по коммитам и сразу видеть, что в них изменилось.

3. **Коммит в один клик.** Вместо `git add . && git commit -m "..."` можно просто ввести сообщение в поле и нажать галочку. VS Code сам добавит все изменения в индекс — экономит время на рутине.

## 1 вещь, которую удобнее делать в терминале

**Интерактивный rebase (`git rebase -i`).** Когда нужно объединить коммиты (squash), изменить их порядок или переписать сообщения — в терминале это делается через простой текстовый редактор, где всё под рукой. В VS Code хоть и есть встроенные инструменты для rebase, но они менее гибкие: сложнее выбрать конкретные коммиты и быстро отредактировать историю. Терминал даёт полный контроль над процессом.
