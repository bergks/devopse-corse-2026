# Сравнение Git vs SVN

## Почему Git "дешевле" SVN
Git "дешевле", чем SVN, потому что в git ветка - это указатель на коммит, а в SVN - это копия директории репозитория. Также первый позволяет быстро переключаться между ветками, благодаря тому, что хранит всю историю локально, а второй требует подключения к центральному серверу

## Можно ли в SVN сделать коммит без интернета?
Нет, нельзя. Потому что здесь все коммиты уходят на центральный сервер, а у разработчика есть только рабочая копия, то есть снимок одной конкретной версии файлов. Поэтому коммит пройти не может, так как новая версия должна быть создана в центральном репозитории, а не локально

## Когда SVN все еще предпочтительнее Git?
- Проекты в госсекторе и банках, потому что переход на гит может быть неоправдан, если система уже больше 10 лет использует SVN
- Если есть необходимость хранить огромные бинарные файлы. Git хранит полную копию файла прои каждом изменении, а SVN только разницу между версиями
- Если необходим жесткий контроль доступа, его можно настроить для отдельных деррикторий
